About mythicpl.us

What is this?

mythicpl.us is a quick reference site for World of Warcraft Mythic+ dungeons. It's built to be fast. There's not a lot of fancy features.

Why?

When mythic plus was first introduced in Legion, it felt like no one had any idea what was going on. The affix schedule was a mystery, no one knew what gear you got from what mythic plus keystone level, etc.
I really hated clicking through a bunch of garbage on a certain well-known WoW site to find the information I wanted.
I ended up cobbling together as much information as I could into a shitty HTML doc that I assembled while I was at work.
This is still that same site, just a little smoother. It's been through a lot of changes. Mostly for the better I think.

Data sources

Affix data comes from Raider.io's API. Blue post data comes from the official Blizzard forums.

Open source

The source code is on GitHub. Contributions and suggestions are welcome.
